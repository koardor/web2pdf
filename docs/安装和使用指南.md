# web2pdf 网页截图 · 安装和使用指南

适用版本：0.2.0　·　浏览器：Microsoft Edge（Chrome 同样可用）

把网页截图保存为 **PDF / PNG / JPEG**，支持四种截图方式。文件名自动带上网页地址，方便存档和分享。

---

## 一、安装

1. 打开 Edge，在地址栏输入 `edge://extensions` 并回车。
2. 打开左下角的 **"开发人员模式"** 开关。
3. 点击 **"加载解压缩的扩展"**，选择插件文件夹 `dist`（里面直接能看到 `manifest.json` 的那一层）。
4. 列表中出现 **"web2pdf 网页截图"** 即安装成功。
5. 点击地址栏右侧的拼图图标 🧩，在 web2pdf 旁点 **"在工具栏中显示"**，蓝色相机图标就会固定在工具栏上。

> **提示**
> - 插件文件夹装好后不要删除或移动，否则插件会失效。
> - Edge 启动时可能提示"关闭开发人员模式扩展"，选择 **保留** 即可。

### 更新到新版本

用新的 `dist` 文件夹覆盖旧文件夹，然后在 `edge://extensions` 里点 web2pdf 卡片上的 **刷新 ⟳** 按钮。卡片上显示的版本号会随之变化。

---

## 二、弹出菜单

点击工具栏上的相机图标，弹出菜单：

| 区域 | 说明 |
|------|------|
| 四个截图按钮 | 可见区域、整个网页、选择区域、选择元素（右侧灰字是快捷键） |
| 格式 | PDF / PNG / JPEG，会记住上次的选择 |
| 保存前预览 | 打开时截完先预览再保存；关闭时截完直接下载。默认打开 |

## 三、四种截图方式

### 1. 可见区域　`Alt+Shift+V`

截取当前屏幕上看到的部分。

### 2. 整个网页　`Alt+Shift+F`

自动从页面顶部滚到底部，拼成一张长图。

- 顶部悬浮的导航栏只保留一次，不会在长图里重复出现。
- 截图时页面会自动滚动，右下角显示"截取中 3/12"之类的进度，**请不要操作页面**，截完会自动回到原来的位置。
- 聊天类网页（例如网页版聊天工具、AI 对话页）的页面本身不滚动，只有对话框在滚动，这种页面用整页只能截到一屏。要截完整对话，请用 **选择元素**。

### 3. 选择区域　`Alt+Shift+S`

自己框选一块区域，**可以超过一屏**。

1. 页面变暗，鼠标变成十字。
2. 按住左键拖出选框。**拖动时可以滚动鼠标滚轮**，选框会跟着延伸；把鼠标拖到窗口上边缘或下边缘，页面也会自动滚动。
3. 松开鼠标后，选框四周出现 8 个小方块，可以拖动它们微调大小。
4. 点 **确认**（或按 `Enter`）截图；点 **取消**（或按 `Esc`）放弃。

> 从任意方向拖都可以，例如从右下往左上拖。

### 4. 选择元素　`Alt+Shift+E`

直接选中网页上的一块内容，例如一篇正文、一个表格、一个对话框。

1. 移动鼠标，光标下的元素会显示橙色高亮框，标签上显示它的名称和尺寸。
2. 高亮的范围不合适时，可以切换层级：
   - **向上滚动滚轮**，或按 **↑**：选中外面一层（更大的范围）。
   - **向下滚动滚轮**，或按 **↓**：回到里面一层。
3. **点击**或按 `Enter` 确认，按 `Esc` 取消。

**元素里有自己的滚动条**（例如聊天记录框、侧边栏、代码框）时，插件会自动滚动框内部，把隐藏在里面的内容全部截出来。**长对话请用这个方式。**

> - 选择元素时滚轮用来切换层级，不会滚动页面。要选页面下方的内容，请先滚到那里，再按快捷键进入选择。
> - 网页里嵌入的子页面（iframe）只能整块选中，不能选它里面的某一部分。鼠标移到它上面后按 `Enter` 确认。

## 四、保存前预览

"保存前预览"打开时，截完会在旁边打开一个预览标签页：

- **查看**：上下滚动查看完整截图。**适应宽度**按窗口大小显示，**原始大小**按实际像素显示，方便检查细节。
- **文件信息**：顶部显示将要保存的文件名、图片尺寸，以及会拆成几个文件。
- **拆分位置**：截图太长需要拆成多个文件时，图上会用红色虚线标出"第 2 个文件从这里开始"。
- **改格式**：可以在预览页改选 PDF / PNG / JPEG，文件名和拆分数量会随之更新。

三个按钮：

| 按钮 | 作用 |
|------|------|
| 保存 | 按所选格式下载，并自动关闭预览页 |
| 重新截图 | 关闭预览，回到原网页，用同样的方式重新截一次 |
| 取消 | 不保存，关闭预览页（直接关掉预览标签效果相同） |

## 五、保存的文件

- **保存位置**：Edge 默认的下载文件夹，不会弹出"另存为"对话框。
- **文件名格式**：`页面标题_网址_日期-时间.扩展名`，例如：
  `如何使用_example.com_docs_guide_20261027-153012.pdf`
  文件名里不允许出现的字符（`/ : ? *` 等）会替换成 `_`，标题或网址太长时会截短。
- **PDF**：整张截图放在一页里，页面和图片一样长，不按 A4 分页。
- **超长自动拆分**：截图太长时会拆成多个文件，文件名末尾加 `_part1`、`_part2`……
  - PDF 每个文件最高约 19,200 像素。
  - PNG / JPEG 每个文件最高 16,384 个屏幕像素。高分屏下每个文件对应的网页长度会短一些。
  - 一次截图总高度最多 100,000 像素，更长的部分不截取（防止无限滚动的页面一直截下去）。

## 六、快捷键

| 快捷键 | 功能 |
|--------|------|
| `Alt+Shift+V` | 可见区域 |
| `Alt+Shift+F` | 整个网页 |
| `Alt+Shift+S` | 选择区域 |
| `Alt+Shift+E` | 选择元素 |

- 快捷键使用弹出菜单里上次选的格式，也遵循"保存前预览"开关。
- 修改快捷键：打开 `edge://extensions/shortcuts`，找到 web2pdf，点击对应的输入框后按下新的组合键。如果和其他软件冲突，在这里改掉即可。

## 七、常见问题

**Q：工具栏图标上出现红色 `!`，什么也没保存？**
截图失败或被中止，常见原因有三种：
- 这个页面不允许截图（见下一条）；
- 截图过程中切换了标签、跳转了页面或关闭了页面；
- 其他错误。

重新截一次即可。如果一直失败，打开 `edge://extensions`，点 web2pdf 卡片上的 **"Service Worker"** 链接，把弹出的控制台里的红色报错信息发给开发者。

**Q：点按钮后提示"此页面不支持截图"？**
`edge://` 开头的浏览器设置页、扩展商店页面、新标签页等是浏览器保护的页面，任何扩展都不能截图。

**Q：本地的 HTML 文件（`file:///` 开头）截不了？**
在 `edge://extensions` 里点 web2pdf 的 **"详细信息"**，打开 **"允许访问文件 URL"**。

**Q：长图里有一截内容重复或缺失？**
有些网页滚动时会动态加载或替换内容（例如无限滚动的信息流、虚拟列表），可能拼不完整。可以先手动把页面滚到底，让内容加载完，再截图；或者分几次用"选择区域"截取。

**Q：长图里某个悬浮按钮或侧栏消失了？**
为了避免悬浮元素在长图里每屏重复出现，从第二屏开始会临时隐藏它们，截完会恢复。

**Q：页面左右方向还有内容没截进去？**
插件只截纵向。宽度以浏览器窗口为准，窗口外横向溢出的部分不会截取。可以把窗口拉宽，或缩小网页显示比例（`Ctrl` + `-`）后再截。

**Q：截出来的图片不够清晰？**
截图按屏幕的实际像素保存，高分屏截出来的图更清晰。需要更清晰时，可以先放大网页（`Ctrl` + `+`）再截，图片像素会相应增加。

**Q：如何卸载？**
在 `edge://extensions` 中找到 web2pdf，点击 **"删除"**。
