# web2pdf 网页截图扩展 设计文档

日期：2026-10-26

## 1. 目的

一个 Edge 浏览器扩展，把网页截图保存成 PDF / PNG / JPEG，用于**存档和分享**。
文件名里带网页地址，以后看文件就知道出处。

## 2. 目标

四种截图方式，各自独立：

| 方式 | 说明 |
|------|------|
| 可见区域 | 截当前视口看到的部分 |
| 整个网页 | 自动从顶滚到底，拼成一张长图 |
| 选择区域 | 鼠标框选；拖动时可滚轮滚页面、拖到窗口边缘自动滚动，选区可超过一屏 |
| 选择元素 | 鼠标悬停高亮元素，点击截取该元素完整内容（含超出视口部分、含元素内部滚动的隐藏内容） |

每种方式都可输出 PDF、PNG、JPEG 三种格式。

## 3. 非目标

- 不保留 PDF 中的可点击链接、不导出可选择文字（PDF 内就是图片）。
- 不做图片标注/编辑、云上传、OCR。
- 不上架商店（本地"加载解压缩的扩展"使用即可；结构上保持可上架）。
- 不支持 Firefox / Safari。

## 4. 反目标（做到了也算失败）

- 长页面拼接出现明显错位、重复、空白条。
- 固定悬浮的顶栏/侧栏在长图中每段都重复出现。
- 超长截图生成一个阅读器打不开或显示空白的 PDF。
- 截图过程中页面被永久改动（滚动位置、隐藏的元素没有还原）。

## 5. 约束与已定决策（用户决定）

- 目标浏览器：**Edge**（Chromium，Manifest V3）。
- 文件名带网址。
- PDF：**整页超长，不按 A4 切分**；每张截图一个 PDF 页面，页面尺寸等于图片尺寸。
- 超过尺寸上限时：**自动拆成多个文件**，文件名加 `_part1`、`_part2`…
- 框选区域、选择元素、整页、可见区域是四个独立功能。
- 框选时必须支持滚轮滚动页面以选取超长区域。
- 可以参考 GitHub 开源项目，不强制基于某个仓库改。

## 6. 我（Claude）做的默认决定（用户可推翻）

- **自写**，参考 mrcoles/full-page-screen-capture、simov/screenshot-capture 的思路；
  PDF 生成用 **jsPDF**（MIT），打包进扩展，不走 CDN。
- **文件名格式**：`页面标题_网址_YYYYMMDD-HHmmss.扩展名`
  - 网址去掉 `https://`，非法字符 `\ / : * ? " < > |` 及空白替换为 `_`，连续 `_` 合并。
  - 标题截断到 50 字符、网址截断到 80 字符，整体不超过 180 字符。
  - 拆分文件：`..._part1.pdf`、`..._part2.pdf`。
- **入口**：点击工具栏图标弹出小菜单：四个截图按钮 + 格式单选（PDF/PNG/JPEG），记住上次的格式。
  另外提供快捷键（建议值，可在 `edge://extensions/shortcuts` 修改）：
  - `Alt+Shift+V` 可见区域、`Alt+Shift+F` 整个网页、`Alt+Shift+S` 选择区域、`Alt+Shift+E` 选择元素（Chrome 系最多 4 个建议快捷键）。
- **保存**：直接下载到 Edge 默认下载目录，不弹另存为对话框（`chrome.downloads`，`saveAs: false`）。
- **JPEG 质量**：0.92。PNG 无损。
- **分辨率**：按设备像素比（高分屏 2x 等）原样截取，保证清晰。

## 7. 各功能行为细节

### 7.1 可见区域
`chrome.tabs.captureVisibleTab` 一次截取，直接输出。

### 7.2 整个网页
1. 记录原始滚动位置。
2. 计算页面总高度（`document.scrollingElement.scrollHeight`）和宽度。
3. 逐屏滚动并截图，拼接到 canvas。
4. 从第二屏开始，临时隐藏 `position: fixed / sticky` 的元素（只隐藏，截完还原），避免重复。
5. 滚动后等待渲染（约 150–300ms，并受 `captureVisibleTab` 每秒调用次数限制约束，需节流）。
6. 截完恢复滚动位置和隐藏的元素。
7. （用户决定）只滚动文档本身。页面本身不滚动、内容在内部容器里滚动的页面（聊天类布局），整页模式只截一屏；完整内容用"选择元素"模式截取。

### 7.3 选择区域
1. 注入全屏遮罩，十字光标，Esc 取消。
2. 按住左键拖动形成选框；拖动中**滚轮可滚动页面**，选框按文档坐标跟随延伸；鼠标贴近视口上/下边缘时自动滚动。
3. 松开后选区定格，显示 8 个调节手柄可微调，并出现"确认 / 取消"按钮（Enter 确认）。
4. 确认后移除遮罩，按选区所在的文档范围逐段滚动截取、拼接、裁剪；固定元素处理同 7.2。

### 7.4 选择元素
1. 进入模式后，鼠标下的元素加高亮边框，并显示标签名和尺寸。
2. **滚轮切换层级**：向上滚选父元素，向下滚回子元素（此模式下滚轮不滚页面；需要的话先滚到目标位置再进入模式）。
3. 点击确认，Esc 取消。
4. 截取：
   - 元素整体超出视口 → 滚动页面分段截取并拼接。
   - 元素**自身有内部滚动**（`scrollHeight > clientHeight` 且 overflow 可滚） → 滚动元素内部分段截取，拼出完整内容；截完还原元素的滚动位置。
   - 两者兼有时（内部可滚的元素本身也比视口高）以合理方式组合；做不到完美时至少保证不出错、内容不缺。

## 8. 尺寸上限与拆分

- PNG/JPEG：单张 canvas 高度上限按 **16,384 设备像素**计（保守值，兼顾面积上限），超过即拆分。
- PDF：单页高度上限 **14,400 pt**（PDF 200 英寸限制）。PDF 页面按 1 CSS 像素 = 0.75pt 换算，
  超过即拆分成多个 PDF 文件（不是同一 PDF 的多页）。
- 拆分点按上限等分，各段尽量等高。
- （Claude 的决定）PDF 页面可以由多条图片带上下无缝拼成，所以 PDF 按 14,400pt 拆分，不受 canvas 上限约束；PNG/JPEG 按 canvas 上限拆分。

## 8.1 范围限制（Claude 的决定）

- **只处理纵向**：截图宽度 = 视口宽度（整页、框选）或元素可见宽度（元素）；横向溢出的内容不截。
- **iframe**：只在顶层页面运行。选择元素时 iframe 可以作为一个整体元素被选中并截取，但不进入 iframe 内部选择子元素，也不滚动 iframe 内部内容。

## 9. 失败与边界

- `edge://`、扩展商店、PDF 查看器等页面不能注入脚本：弹出菜单里提示"此页面不支持截图"。
- 截图中途页面导航/关闭标签：放弃并提示。
- 无限滚动页面：以开始截图时测得的高度为准，不追加加载出来的新内容（可设一个总高度硬上限，比如 100,000 CSS 像素，防止卡死）。
- 进度：整页/长选区截取时在页面角落显示简单进度（"截取中 3/12"），截取那一帧之前隐藏自身。

## 10. 留给实现者决定

- 代码结构（service worker / content script / offscreen document 分工）、是否用构建工具（倾向不用，纯 JS）。
- 拼接时 canvas 放在哪（content script 或 offscreen document），只要满足尺寸上限。
- 具体等待时长、节流策略。
- 弹出菜单的视觉样式（简洁即可，中文界面）。
- 图标。

## 10.1 保存前预览（2026-10-27 追加，用户决定）

- 弹出菜单"保存前预览"开关，默认打开，记住设置；快捷键也遵循。
- 打开时：截完不下载，在原标签右侧新开预览页：完整截图可滚动，"适应宽度 / 原始大小"切换，显示文件名、尺寸、将拆成几个文件，并在图上标出每个文件的起点。
- 预览页可改格式（默认上次的格式，保存后记住）；按钮：保存（下载后关闭预览）、重新截图（回到原标签用同一方式重截）、取消（不保存）。直接关闭预览标签等同取消。
- 实现（Claude 的决定）：拼接先产出若干张无损 PNG 中间段（每段不超过单张 canvas 上限），预览直接显示这些段；保存时再按所选格式的上限拆分、逐行复制编码。关闭预览时不经过预览也走同一流程。

## 11. 验收

在 Edge 中加载解压缩的扩展后，在以下页面上四种方式 × 三种格式都能正常保存：
- 普通短页面、带固定顶栏的长文章、内部可滚动的聊天/侧栏类页面（该类页面上整页模式截一屏即合格，选择元素模式须截出完整内容）、超过上限需要拆分的超长页面。
文件名符合第 6 节格式；截完页面状态复原。
