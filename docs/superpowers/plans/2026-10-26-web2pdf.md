# web2pdf 网页截图扩展 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个 Edge（MV3）扩展，四种截图方式（可见区域 / 整个网页 / 选择区域 / 选择元素）× 三种格式（PDF / PNG / JPEG），文件名带网址，超长自动拆分。

**Architecture:** Service worker（`background.js`，经典脚本，`importScripts` 引入 `lib/`）统筹：注入 content scripts 让用户选择目标并返回"分块计划"（tiles），然后逐块让 content 滚动、自己节流调用 `captureVisibleTab`，把每块图片发给 offscreen document；offscreen 用 canvas 拼接、按上限拆分、编码 PNG/JPEG 或用 jsPDF 生成 PDF，返回 blob URL，service worker 用 `chrome.downloads` 保存。纯计算逻辑放在 `src/lib/`，同时可在浏览器和 Node 里运行，用 `node --test` 测试；DOM/浏览器部分用 `test/pages/` 里的测试页手动验证。

**Tech Stack:** 纯 JavaScript，无构建工具；Manifest V3；jsPDF 2.5.2（UMD，打包到 `vendor/`）；Node 24 内置测试运行器。

**Spec:** `docs/superpowers/specs/2026-10-26-web2pdf-design.md`

## Global Constraints

- 目标浏览器 Edge（Chromium），Manifest V3，本地"加载解压缩的扩展"使用；界面文字为中文。
- 文件名：`页面标题_网址_YYYYMMDD-HHmmss.扩展名`；网址去掉 `http://`/`https://`；`\ / : * ? " < > |`、空白、控制字符替换为 `_`，连续 `_` 合并、首尾 `_` 去掉；标题 ≤50 字符、网址 ≤80 字符、整体 ≤180 字符；拆分时加 `_part1`、`_part2`…；空标题用 `untitled`。
- PDF 一张截图 = 一个 PDF 文件的一页，页面尺寸 = 图片尺寸（1 CSS px = 0.75pt），不按 A4 切。
- 拆分上限：PNG/JPEG 单张 canvas 高 ≤16,384 设备像素；PDF 单页高 ≤14,400pt（= 19,200 CSS px），PDF 页内由多条 canvas 图片带无缝拼成；超出即拆成多个**文件**，各段等高。
- 截取总高度硬上限 100,000 CSS px。
- 只处理纵向：宽度 = 视口宽度（整页/框选）或元素在视口内的可见宽度（元素）。
- 只在顶层 frame 运行；iframe 可被当作整体元素截取。
- 整页模式只滚动文档本身；内部滚动容器的完整内容由选择元素模式负责。
- JPEG 质量 0.92；PDF 内图片用 JPEG 0.92 嵌入（Claude 的决定，控制体积）；按设备像素比原样截取。
- 直接下载到默认目录（`saveAs: false`）；弹出菜单记住上次格式（`chrome.storage.local` 键 `format`，默认 `'pdf'`）。
- 快捷键建议值：`Alt+Shift+V` 可见、`Alt+Shift+F` 整页、`Alt+Shift+S` 区域、`Alt+Shift+E` 元素。
- 截完必须还原：滚动位置（页面和元素内部）、隐藏的固定元素、注入的遮罩/提示。
- `captureVisibleTab` 调用间隔 ≥550ms（Chromium 限制每秒 2 次）。

## Review Focus

1. **目标元素本身在 fixed/sticky 容器里**（聊天界面常见）：隐藏固定元素时不能隐藏目标的祖先或目标本身，否则截出空白。→ Task 6 Step 5 的 `chat.html` 检查。
2. **页面/元素比视口还短**：只截一块、不滚动、不留空白。→ Task 2 `planTiles` 测试 "short target"。
3. **框选从下往上拖、从右往左拖**：选区要规范化为正宽高。→ Task 2 `normalizeRect` 测试。
4. **截取中途切换页面或关闭标签**：中止、不下载残缺文件、不留遮罩，徽标提示。→ Task 7 Step 3 手动检查。
5. **非整数缩放（系统缩放 125%/150%、浏览器 Ctrl+ 缩放）**：拼接处不能出现 1px 缝隙或重叠。→ Task 2 `tileDrawRect` 相邻块无缝测试。

## 消息协议（所有任务共用）

Content script 由 background 用 `chrome.scripting.executeScript({target:{tabId}, files:[...]})` 注入，顺序：`src/lib/tiles.js`, `src/content/agent.js`, `src/content/region.js`, `src/content/element.js`。agent 用 `window.__w2pInstalled` 防重复注册监听。

**Tile（分块）**：`{ pageScroll: number, innerScroll: number|null, clip: {x, y, w, h}, destY: number }` —— 全部 CSS px；`clip` 是截图时在视口里的裁剪框；`destY` 是在成品图里的纵向位置。
**Job**：`{ tiles: Tile[], width: number, height: number, viewportW: number }`（`width`/`height` 为成品 CSS px 尺寸，`viewportW = window.innerWidth`）。

background → content（`chrome.tabs.sendMessage`）：

| type | 参数 | 回复 |
|------|------|------|
| `w2p:select` | `{mode: 'visible'\|'page'\|'region'\|'element'}` | `{ok:true, job}` 或 `{ok:false, cancelled:true}` |
| `w2p:step` | `{index}` | `{ok:true}`：已滚动到位、`index>0` 时已隐藏固定元素、进度提示已隐藏、已等待渲染 |
| `w2p:progress` | `{done, total}` | `{ok:true}` 显示"截取中 done/total" |
| `w2p:restore` | — | `{ok:true}` 还原一切 |

background → offscreen（`chrome.runtime.sendMessage`，带 `target:'offscreen'`）：

| type | 参数 | 回复 |
|------|------|------|
| `w2p:compose-begin` | `{width, height, format:'pdf'\|'png'\|'jpeg'}` | `{ok:true}` |
| `w2p:compose-tile` | `{dataUrl, clip, destY, viewportW}` | `{ok:true}` |
| `w2p:compose-end` | — | `{ok:true, files:[{url, part}]}`，`part` 单文件时为 `null`，否则从 1 起 |
| `w2p:revoke` | `{urls}` | `{ok:true}` |

popup → background：`{type:'w2p:start', mode, format, tabId}` → 立即回复 `{ok:true}` 或 `{ok:false, error:'unsupported'}`，然后 popup 关闭，background 继续。

### Task 2: 分块与拆分计算

**Files:**
- Create: `src/lib/tiles.js`
- Test: `test/lib/tiles.test.js`

**Interfaces:**
- Produces（全局 `Web2pdf.*` 与 CommonJS）：
  - `planTiles({top, height, viewportHeight, scrollMax}) -> Array<{scroll, offsetInView, destY, h}>` —— 单一滚动轴上的分块；`top`/`height` 是目标在滚动内容坐标里的范围。
  - `planSplits(total: number, limit: number) -> Array<{start, end}>` —— 等高分段。
  - `splitLimitCss(format, dpr) -> number` —— `pdf` 返回 `19200`；`png`/`jpeg` 返回 `Math.floor(16384 / dpr)`。
  - `normalizeRect(x1, y1, x2, y2) -> {x, y, w, h}`
  - `tileDrawRect(destY: number, h: number, scale: number) -> {dy, dh}` —— `dy = Math.round(destY*scale)`，`dh = Math.round((destY+h)*scale) - dy`。
  - 常量 `MAX_TOTAL_HEIGHT = 100000`。

- [ ] **Step 3: 实现 `src/lib/tiles.js`。** `planTiles` 算法（先把 `height` 截到 `MAX_TOTAL_HEIGHT`）：

```
cursor = top; end = top + height
while cursor < end:
  scroll = min(cursor, scrollMax)
  off = cursor - scroll
  h = min(end, scroll + viewportHeight) - cursor
  push {scroll, offsetInView: off, destY: cursor - top, h}
  cursor += h
```

`planSplits`：`n = ceil(total/limit)`，`size = ceil(total/n)`，最后一段到 `total`。
