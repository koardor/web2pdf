# web2pdf 网页截图

Edge 扩展：把网页截图保存成 PDF / PNG / JPEG，文件名带网址。

| 方式 | 快捷键 | 说明 |
|------|--------|------|
| 可见区域 | Alt+Shift+V | 当前屏幕 |
| 整个网页 | Alt+Shift+F | 从顶滚到底拼成长图（页面本身不滚动的聊天类页面只截一屏） |
| 选择区域 | Alt+Shift+S | 拖动框选；拖的同时可滚轮，贴近上下边缘自动滚动；松开后可拖手柄微调，Enter 确认 |
| 选择元素 | Alt+Shift+E | 悬停高亮，滚轮或 ↑/↓ 切换上级/下级，点击或 Enter 确认；元素内部有滚动条时会截出全部内容 |

快捷键使用弹出菜单里上次选的格式。快捷键可在 `edge://extensions/shortcuts` 修改。

## 安装

1. 打开 `edge://extensions`，打开左下角"开发人员模式"。
2. 点"加载解压缩的扩展"，选择本文件夹（含 `manifest.json` 的那一层）。
3. 把工具栏上的扩展图标固定出来。

## 输出规则

- 文件名：`页面标题_网址_YYYYMMDD-HHmmss.扩展名`，直接存到 Edge 默认下载目录。
- PDF 是一整页超长页面（不按 A4 切）。
- 超长时自动拆成多个文件（`_part1`、`_part2`…）：PDF 每个文件最高约 19,200 像素，PNG/JPEG 最高 16,384 设备像素；总高度上限 100,000 像素。
- 截图失败或中途切换/关闭页面时，图标上显示红色 `!` 3 秒，不会下载残缺文件。
- `edge://` 页面、扩展商店等浏览器页面不能截图。

## 开发

```bash
npm test                 # 纯逻辑与后台调度的自动测试
node tools/serve.js      # 本地服务 http://localhost:8000/ ，打开 test/pages/ 下的测试页
node tools/make-icons.js # 重新生成图标
```

`test/harness/` 里是在普通网页中模拟扩展环境的测试工具（拼接、页面脚本）。

## 验收清单（在 Edge 中手动）

先 `node tools/serve.js`，加载扩展，然后逐项检查：

- [ ] `test/pages/short.html`：可见区域 × PDF / PNG / JPEG，内容与屏幕一致、清晰。
- [ ] `test/pages/long-fixed-header.html`：整页 → 色带 1–12 连续，黑色顶栏只在最上面出现一次，"第二节"标题在原位；截完页面回到原位置。
- [ ] 同页：选择区域，从第 3 条拖到第 9 条，过程中滚轮 → 恰好覆盖 3–9；再试一次贴边自动滚动；从右下往左上拖；Esc 取消无残留。
- [ ] `test/pages/huge.html`：整页 PNG 与 PDF 各拆成多个 `_partN` 文件，衔接处色带连续，PDF 能在 Edge 打开。
- [ ] `test/pages/chat.html`：选择元素点消息列表 → 消息 1–200 全部在、不重复，日期头不重复，周围不是空白；整页模式只截一屏。
- [ ] `test/pages/tall-scroller.html`：选择元素选紫框 → 行 1–60 全部在。
- [ ] 截 `huge.html` 整页过程中点浏览器后退或关闭标签 → 无下载，图标出现红色 `!`。
- [ ] 四个快捷键各试一次。
- [ ] 浏览器缩放 125% 下整页截 `long-fixed-header.html`，拼接处无缝隙。
- [ ] 一个真实长文章网站、一个真实聊天网站各试整页与选择元素。
